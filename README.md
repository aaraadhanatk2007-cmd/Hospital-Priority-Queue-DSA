# Hospital Priority Queue Using Max Heap

## Problem
A hospital uses a priority queue to manage patients according
to severity. A higher severity score represents a higher priority.

## Input
45, 72, 30, 90, 65, 50, 85

## Programs Implemented
1. Max Heap Insertion
2. Heap Sort
3. Quick Sort

## Results
Final sorted order:
30, 45, 50, 65, 72, 85, 90

Max Heap:
Comparisons = 9
Swaps = 5
Height = 2

Heap Sort:
Comparisons = 21
Swaps = 18

Quick Sort:
Comparisons = 12
Swaps = 6

## Conclusion
A Max Heap is suitable for the hospital priority queue because
it supports continuous insertion and provides immediate access
to the highest-priority patient.
